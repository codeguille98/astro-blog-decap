# HTML y la estructura de una página web

HTML es el lenguaje utilizado para definir la estructura de una página web.

Gracias a HTML podemos crear títulos, párrafos, enlaces, imágenes y muchos otros elementos.

## Elementos HTML

Una página está formada por diferentes elementos.

Por ejemplo, podemos utilizar `h1` para los títulos principales y `p` para los párrafos.

## La importancia de la estructura

Una estructura HTML correcta ayuda a crear páginas más accesibles y fáciles de mantener.
