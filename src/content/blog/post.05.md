# CSS para mejorar nuestro diseño

CSS permite controlar la apariencia visual de nuestras páginas web.

Podemos modificar colores, tamaños, espacios, fuentes y muchas otras propiedades.

## Colores

Los colores permiten crear una identidad visual para nuestro proyecto.

## Espaciado

Las propiedades de margen y padding permiten controlar el espacio entre los diferentes elementos.

## Diseño responsive

También podemos utilizar CSS para conseguir que nuestra página se adapte a diferentes tamaños de pantalla.
