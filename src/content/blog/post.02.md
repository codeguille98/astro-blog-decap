# Componentes en Astro

Los componentes son una parte fundamental de Astro.

Permiten dividir una aplicación en pequeñas partes reutilizables.

## Ventajas de los componentes

Utilizar componentes hace que nuestro código sea más organizado y fácil de mantener.

Por ejemplo, en nuestro proyecto hemos creado un componente llamado `Menu.astro`.

## Reutilización

Una de las ventajas principales es que podemos utilizar el mismo componente en diferentes páginas.

Esto evita tener que repetir el mismo código constantemente.
