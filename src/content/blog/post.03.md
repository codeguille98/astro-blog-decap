# Introducción a JavaScript

JavaScript es uno de los lenguajes más utilizados en el desarrollo web.

Permite añadir interactividad y comportamiento dinámico a las páginas.

## Variables

Las variables permiten almacenar información que podemos utilizar posteriormente.

Por ejemplo, podemos almacenar nombres, números o diferentes tipos de datos.

## Funciones

Las funciones permiten agrupar instrucciones que podemos ejecutar cuando las necesitamos.

Son una herramienta fundamental para organizar nuestro código.
