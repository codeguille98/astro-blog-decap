# Introducción a Astro

Astro es un framework moderno para crear sitios web rápidos y eficientes.

Una de sus principales características es que permite enviar muy poco JavaScript al navegador cuando no es necesario.

En este blog aprenderemos diferentes conceptos relacionados con Astro y el desarrollo web.

## ¿Por qué utilizar Astro?

Astro está especialmente pensado para crear sitios de contenido, blogs y páginas web rápidas.

Además, permite utilizar diferentes tecnologías y frameworks dentro de los componentes cuando es necesario.
