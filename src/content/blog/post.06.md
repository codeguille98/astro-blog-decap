# Markdown para crear contenido

Markdown es un formato sencillo que permite escribir contenido utilizando una sintaxis fácil de aprender.

## Títulos

Podemos crear títulos utilizando el símbolo `#`.

Por ejemplo:

# Título principal

Y también podemos utilizar diferentes niveles de encabezados.

## Listas

Markdown permite crear listas de una manera sencilla.

- Primer elemento
- Segundo elemento
- Tercer elemento

Esto resulta especialmente útil para escribir los artículos de nuestro blog.
