# Ventajas de utilizar Astro

Astro está diseñado para crear sitios web rápidos y modernos.

Una de sus características principales es su enfoque en el rendimiento.

## Poca cantidad de JavaScript

Astro permite enviar al navegador solamente el JavaScript que realmente necesita la página.

## Contenido estático

También es una herramienta muy adecuada para blogs y sitios de contenido.

## Componentes

Podemos utilizar componentes para organizar nuestro proyecto y reutilizar código.
