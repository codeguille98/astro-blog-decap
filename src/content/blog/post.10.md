# Publicar un proyecto Astro

Una vez terminado nuestro proyecto podemos publicarlo para que otras personas puedan acceder a él.

Existen diferentes servicios que permiten realizar este proceso.

## Preparar el proyecto

Antes de publicar debemos comprobar que nuestra aplicación funciona correctamente.

También debemos asegurarnos de que todas las dependencias están correctamente instaladas.

## Deploy

Servicios como Netlify permiten conectar un repositorio Git y desplegar automáticamente nuestro proyecto.

En este proyecto utilizaremos Netlify para publicar nuestro blog.
