# ¿Qué es el desarrollo web?

El desarrollo web consiste en crear y mantener sitios y aplicaciones que funcionan en Internet.

Existen diferentes tecnologías que permiten construir una página web.

## Frontend

El frontend es la parte de una aplicación que interactúa directamente con el usuario.

HTML, CSS y JavaScript son algunas de las tecnologías fundamentales del frontend.

## Backend

El backend se encarga de la lógica que funciona en el servidor.

Ambas partes trabajan juntas para crear aplicaciones web completas.
