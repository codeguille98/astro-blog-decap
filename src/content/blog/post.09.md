# Introducción a Git

Git es un sistema de control de versiones utilizado para gestionar proyectos de software.

Permite guardar diferentes versiones de nuestro código.

## Repositorios

Un repositorio contiene los archivos y el historial de cambios de un proyecto.

## Commits

Los commits permiten guardar cambios realizados en nuestro proyecto.

Utilizar Git es especialmente útil cuando trabajamos en proyectos grandes o colaborativos.
